# Micrositio de Diagnóstico Comercial (VQI) — Prosper IA

Este es un micrositio de diagnóstico comercial interactivo diseñado para captar leads B2B calificando el estado de sus pipelines en tiempo real.

## Características
*   **Estética Premium:** Tema oscuro estilo Glassmorphic con variables de color e identidad de Prosper IA.
*   **Interactividad dinámica:** Cuestionario paso a paso con contadores animados y render SVG del embudo (pipeline funnel).
*   **Cálculo lógico real:** Algoritmos que determinan la ineficiencia operativa y la fuga de ingresos mensuales en dólares basada en velocidad de respuesta (Speed-to-Lead), desorganización administrativa y auditorías comerciales.
*   **CTA Integrado:** Conexión directa con la landing de conversión de agendamientos confirmada por el dueño.

## Cómo probar localmente
Para iniciar el servidor estático local y probar el micrositio de diagnóstico en tu navegador:

1.  Abre una terminal y colócate en esta carpeta:
    ```bash
    cd /Users/ejimenezsys/Desktop/Cortexia/777_cortexia_v15.2_Ejimenezsys/DOCS/CONTENIDO/PROYECTOS/prosper_ia/landings/diagnostico
    ```
2.  Inicia el servidor local de Python:
    ```bash
    python3 -m http.server 3004
    ```
3.  Abre en tu navegador la siguiente dirección:
    [http://localhost:3004](http://localhost:3004)
